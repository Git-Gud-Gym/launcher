# Finding your game

When it starts, the app looks for your game by itself. For Elden Ring, it searches for `eldenring.exe` in these
places, in order:

1. Every Steam library listed in Steam's settings, including libraries on other drives.
2. The folder Steam's uninstaller records for the game.
3. Common folders on every drive, such as `X:\SteamLibrary`, `X:\Games\ELDEN RING` and `Program Files`.

The location shows in the sidebar under **Game location**.

## If it's wrong or missing

- Click **Browse…** and pick the game's exe yourself. For Elden Ring, that's `eldenring.exe` inside the game's
  `Game` folder.
- Click **Auto-detect** to run the search again, for example after installing the game or adding a Steam library.

## Starting the game yourself

That works too. The app remembers wherever it sees the game running, and attaches as soon as the game has
loaded, as long as Easy Anti-Cheat isn't running (see [Playing offline](/docs/offline)).
