# Git Gud Gym website

Marketing site and docs for Git Gud Gym, deployed to GitHub Pages by
[`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

Vite + React 18 + TypeScript + Tailwind CSS 3, react-router, framer-motion. Docs are Markdown rendered with
react-markdown + remark-gfm.

## Commands

Run from this folder (Node 20+):

```sh
npm install        # or: npm ci
npm run dev        # dev server at http://localhost:5173/git-gud-gym/
npm run build      # type-check (tsc -b) + production build into dist/
npm run preview    # serve dist/ at http://localhost:4173/git-gud-gym/
npm run typecheck  # type-check only
```

The base path comes from `SITE_BASE` (default `/git-gud-gym/`), e.g. `SITE_BASE=/ npm run build` for a custom
domain or a `<owner>.github.io` repo. CI sets it to `/<repo name>/`.

## Where things live

| Path | What |
|---|---|
| `src/config.ts` | `REPO` and every GitHub URL derived from it. The only place the owner/repo is written. |
| `src/catalog.ts` | Catalog types (schema 1), loader and helpers. |
| `src/data/sample-catalog.json` | Fallback catalog used when `catalog.json` can't be fetched. Real facts only. |
| `src/docs/*.md` | Docs pages. Register new ones in `src/docs/index.ts`. |
| `src/pages/` | Home, Games, Docs, 404. |
| `src/components/` | Layout, nav, footer, game cards, home sections, Markdown renderer. |
| `public/` | Logo, favicon, app screenshot. |

## The catalog

At runtime the site fetches `<base>catalog.json`. In CI it's generated by `scripts/build-catalog.mjs`
(`--out site/public/catalog.json`); if that fails, the workflow publishes the sample catalog instead. Locally
there's usually no `public/catalog.json` (it's gitignored), so the site falls back to the bundled sample. To try a
real one, drop a `catalog.json` into `public/`.

The desktop app reads the same file from the deployed site, so keep the schema stable.

## Writing docs

- Link between pages with absolute site paths: `[Hotkeys](/docs/hotkeys)`, `[games](/games)`.
- Use `{{RELEASES_URL}}`, `{{ISSUES_URL}}`, `{{NEW_ISSUE_URL}}`, `{{DISCUSSIONS_URL}}`, `{{CONTRIBUTING_URL}}`,
  `{{GITHUB_URL}}`, `{{CHANGELOG_URL}}`, `{{LICENSE_URL}}`, `{{CATALOG_URL}}` instead of hardcoding GitHub links.
- GitHub-style callouts work: `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`.
- Inline code that is just a function key (`` `F5` ``) renders as a key cap.
- Raw HTML is not rendered.

## Deep links on GitHub Pages

The build copies `index.html` to `404.html`, so a direct visit to e.g. `/git-gud-gym/docs/stats` loads the app and
the router renders the right page (GitHub serves it with a 404 status, which browsers ignore).
