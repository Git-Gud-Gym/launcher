# Code of Conduct

Git Gud Gym follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient with people who are learning (that's the whole point of a
practice tool), give and accept constructive feedback gracefully, and don't harass anyone. Insults,
personal attacks, sexualised language, doxxing and trolling aren't tolerated in issues, pull
requests, discussions or any other project space.

**Enforcement:** report unacceptable behaviour privately to the maintainers through
[GitHub's private vulnerability / contact form](../../security/advisories/new) or by email to the
repository owner. Every report is reviewed and kept confidential. Maintainers may remove content
and warn, suspend or ban participants, following the Covenant's enforcement guidelines.
